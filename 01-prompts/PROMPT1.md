we are building an image editor sidecar for antigravity (you) - the purpose of this side car is to spin up a webpage that is integrated with the current session of antigravity so that the user can sketch things (with a full paint-like interface) and the sketch is automatically imported in the antigravity session. the paint interface will also allow opening image files in the current workspace for editing and refining the image using nano banana models (nano banana pro, nano banana 2 or nano banana 2 lite). 

the main operations in the pain window will be:
- free drawing and paiting in a blank canvas with typical image editor tools, supporting primitives, layers and transparency
- a refine button with an optional prompt and a model selector to take the drawing and generate a new AI polished layer
- import functionality to open a file from the workspace (or computer)
- export functionality to save a file to the workspace
