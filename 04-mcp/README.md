## Key Point

- **Where MCP shines**: Low-latency external knowledge and documentation retrieval (e.g. Google Developer Knowledge MCP) without hallucinating APIs.
- **The pitfall**: Connecting dozens of MCP tools bloats the system prompt with JSON schemas on every turn, causing tool misrouting and context exhaustion.
- **The alternative**: Use CLI tools and Just-In-Time skills for deterministic operations.
